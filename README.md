# Sales-Performance-Customer-Insights-Revenue-Trends-Discounts-Behavioral-Analysis
Sales performance analysis dashboard using Excel
## Project Overview
This project analyzes sales performance data to uncover revenue trends, customer behavior, product performance, and payment preferences.

## Objectives
- Analyze total revenue
- Identify top-performing products
- Evaluate discount impact
- Understand customer purchasing patterns
- Build an interactive dashboard

## Tools Used
- Excel
- Pivot Tables
- Data Cleaning Techniques

## Data Cleaning Process
- Removed blanks
- Checked logical duplicates
- Standardized categories
- Validated pricing calculations
- Added calculated tables

## Key Insights
- Top-performing product categories generated the highest revenue
- Discounts influenced customer purchase behavior
- Card payments were the most used payment method
- Sales peaked during specific periods
